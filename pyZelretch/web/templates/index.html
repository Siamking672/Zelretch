Welcome to Zelretch

A Kurigram-based pluggable Telegram userbot - rewritten from Ultroid.

Complete the three-step setup below to deploy your bot. Your configuration is stored in the database you pick (not in .env files), so future deployments can be restored simply by pointing Zelretch at the same DB.

1. Core Variables

Telegram API credentials, owner ID, and your database choice.

1b. Restore Existing

Already deployed Zelretch before? Import config from your existing DB.

2. Session

Provide a Kurigram session string or generate one with the in-wizard tool.

3. Deploy

Review your configuration and start the bot.
